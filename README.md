# ✦ Wotan Toolbox

An educational activity library built with HTML, CSS and JavaScript.

## Main categories

- Reading / Lectura
- Games / Juegos

## Project structure

- `index.html` - Main homepage
- `style.css` - Shared website styling
- `lectura/` - Reading activities catalogue
- `games/` - Games catalogue
- `assets/` - Shared media and resources

## Adding a new activity

1. Create a folder inside the appropriate category under `games/ or /reading`.
2. Add an `index.html` file.
3. Add CSS and JavaScript files if necessary.
4. Add a new activity card to the corresponding category page.
5. Commit your changes.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Languages

English and Spanish.
